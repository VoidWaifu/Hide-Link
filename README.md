# Hide Link 🔗

**Спрячь свою ссылку — бесплатно, анонимно, без регистрации.**

[Открыть приложение](https://voidwaifu.github.io/Hide-Link/)

## Что это?

Hide Link — браузерное приложение, которое **маскирует URL-адреса**. Оно не сокращает ссылки, а скрывает их под нечитаемым кодом.

## Зачем?

- 🔒 **Приватность** — никто не увидит, куда ведёт ссылка
- 🎭 **Маскировка** — скрывает реферальные и партнёрские метки
- 💬 **Чистый вид** — ссылка выглядит как случайный набор символов

## Как работает?

1. Вставляете ссылку
2. Выбираете режим: **обычный** или **0oO** (похожие символы)
3. Получаете замаскированную ссылку вида:
   ```
   https://voidwaifu.github.io/Xk3fQz9pLm2R
   ```

## Особенности

- ✅ Бесплатно и без ограничений
- ✅ Без регистрации и баз данных
- ✅ Ссылки хранятся только у вас (localStorage)
- ✅ Два режима маскировки

## Технологии

Чистый **HTML + CSS + JavaScript**. Никаких серверов — всё работает в браузере.
